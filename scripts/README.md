# scripts

The public installers for Freedom.

`bootstrap.sh` and `preflight.sh` are **copies** of the same files in the private
`ContinentalWorks/freedom-dev` repo, published here because the install
command has to be fetchable by someone who does not yet have access to anything.

That makes this a mirror, and mirrors drift. The last one did: `SupersuitUp/paos-docs`
served a bootstrap that diverged from the template by 193 lines and still called the
product "a Personal Agentic OS" months after the rename, while the wiki pointed every
new operator at it. **When you change a script in the template, copy it here in the
same sitting, or the advertised install is not the install you tested.**

The template is the source. This is the distribution copy.
